# Roadmap Use Cases — Plateforme de gestion de campagnes JDR

---

# MVP — Priorité P1 (Essentiel)

Ces use cases constituent le cœur du produit.
Sans eux, la plateforme ne répond pas aux besoins principaux des MJ.

---

# 1. Créer une campagne

## Priorité
P1 — Critique

## Description
Le MJ crée une nouvelle campagne depuis zéro ou à partir d’un modèle existant.

## Ce que permet le use case
- Nommer la campagne
- Définir l’univers
- Ajouter une description
- Choisir un template de départ
- Organiser la structure initiale

## Personas concernés
- Emma → commencer facilement
- Rémi → gagner du temps
- Julien → créer et archiver proprement

---

# Résumé V2 — Arcane Chronicles

**L'idée** : un modèle économique et un assistant intelligent pour le MJ.

- **Contenus premium** : campagnes, packs de personnages, de monstres, d'objets et de cartes payants, achetés sans quitter le site (paiement intégré via un prestataire certifié), puis utilisables comme ses propres contenus.
- **Assistant IA** : aide à la conception (idées de PNJ, quêtes, lieux, énigmes, narration, vérification de cohérence) et assistant de partie pour le MJ (indices, avertissements, rappels de règles, résumé de session). L'IA propose, le MJ décide.
- **Piste conservée** : un second système de jeu de rôle.

À trancher : qui vend les contenus premium, achat à l'unité ou abonnement, fournisseur d'IA, accès à l'IA (premium ou quota gratuit). Aucun ticket encore créé dans Jira.
